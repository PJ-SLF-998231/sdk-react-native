# Size report

Generated by `example/scripts/size-report.mjs`; do not edit by hand. Numbers are from one machine and one set of dependency versions (see `example/package.json`).

## Example app vs. baseline

The example (`example/App.js`) imports only `@pj-slf-998231/sdk-react-native/camera` and renders one `CameraButton`. The baseline (`example/baseline/App.js`) is the same screen with a plain button and no SDK and no `expo-image-picker`. Both are exported with `expo export` (Metro, release mode).

| Platform | Format | Example | Baseline (no SDK) | Delta | Delta gzip |
|---|---|---|---|---|---|
| ios | Hermes bytecode (.hbc) | 1619.4 KiB | 1510.8 KiB | +108.7 KiB | +51.0 KiB |
| ios | JS, minified (--no-bytecode) | 1011.6 KiB | 962.1 KiB | +49.5 KiB | +16.4 KiB |
| android | Hermes bytecode (.hbc) | 1624.5 KiB | 1515.8 KiB | +108.8 KiB | +51.0 KiB |
| android | JS, minified (--no-bytecode) | 1016.5 KiB | 967.0 KiB | +49.5 KiB | +16.4 KiB |

The delta is the SDK camera entry (client, outbox, cache, theme, capture button) plus `expo-image-picker`, since the baseline has neither. It is not the whole bundle and not an install size.
